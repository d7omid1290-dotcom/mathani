# مثاني — احفظ ما تفهم، وافهم ما تحفظ

رفيق ذكي لحفاظ القرآن يغطي **المصحف كاملاً برواية حفص (114 سورة، 604 أوجه)** وطلاب الحلقات: يكشف أخطاء التسميع، ويتعرّف على **الانتقال إلى الآيات المتشابهة** ويشرح الفرق وسببه من التفسير المعتمد، ويبني مراجعة متباعدة من أخطاء الطالب.

المسار الثالث — تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي 2026.

**جرّب التطبيق:** https://d7omid1290-dotcom.github.io/mathani/ (على الجوال، ويُفضَّل Google Chrome للتسميع الصوتي).

**الفريق:** فريق إتقان، يزن عبدالله العوبثاني وعبدالرحمن سعيد مسعود.

## التطبيق
تطبيق ويب للجوال بخمسة أقسام: الرئيسية، المصحف، **سمّع** (زر أوسط)، التفسير، حسابي.
ومعها: **المساعد القرآني** (محادثة بالصوت أو الكتابة، ومكالمة صوتية متواصلة)، و**الورد اليومي** والبستان، والمراجعة المتباعدة، ومواقيت الصلاة والقبلة، وغرفة تسميع مباشرة، والواجهة بالعربية والإنجليزية والأردية.
الفهم والتدبر في «المصحف»، والتسميع في قسم مستقل خاص به.

### التسميع
- **تسجيل صوتي:** يُسجَّل الصوت ويُحفظ على الجهاز، ثم يتعرف عليه نموذج **Whisper داخل المتصفح** (transformers.js) ويُقيَّم. ويمكن بدلاً من ذلك ضبط `ASR_ENDPOINT` لإرسال التسجيل إلى خادم بنموذج مدرّب على التلاوة.
- **تسميع مباشر:** التعرف على الكلام في المتصفح أثناء القراءة (Chrome).
- **بالكتابة:** بديل يعمل في كل مكان.

## المصحف
كل وجه يُعرض بأسطره الخمسة عشر كما في مصحف المدينة: كل سطر يبدأ وينتهي عند الكلمات نفسها التي في المطبوع، والأسطر مضبوطة الطرفين، ويُحسب حجم الخط ليتسع الوجه للشاشة. وضع قراءة كامل: الأدوات تظهر باللمس، والضغط المطوّل على الآية يعرض معناها ومتشابهها.
```bash
python3 scripts/build_layout.py   # يربط تخطيط الأسطر بنص حفص (يتطلب data/layout_raw)
```

## السماع
٤٢ قارئاً برواية حفص (منهم المصحف المعلّم للحصري والمنشاوي)، تُشغَّل آيةً آية مع تظليل الآية في المصحف وتقليب الوجه تلقائياً، وتكرار كل آية (حتى بلا توقف)، والسرعة، و«وقت للترديد» بعد كل آية. الملفات من EveryAyah.

## قارئ الوجه والتسميع
| المرحلة | ما يحدث |
|---|---|
| افهم | موضوع الوجه، ومقاصد السورة، ومعنى كل آية (التفسير الميسر)، وغريب الكلمات (السراج)، وأسباب النزول الصحيحة فقط |
| احفظ | تمييز الآيات التي لها متشابه، ومقارنة ملوّنة للفروق مع سياق كل موضع، ووضع إخفاء الآيات |
| سمّع | ثلاث طرق: **تسجيل التلاوة** (يُحفظ الصوت ويُقيَّم)، والتسميع المباشر، والكتابة. مع تلميح متدرج: المعنى ← أول كلمة ← الآية |
| عالج | نسبة الإتقان، والإسقاط والإبدال والزيادة كلمة بكلمة، وعلاج الانتقال إلى المتشابه بالمقارنة والسياق، وإعادة الاستماع للتسجيل |
| ثبّت | عمل اليوم، والأوامر والنواهي (اقتباس حرفي مُتحقق منه)، والفوائد، واختبارات مولّدة من نص المصحف |

ومن «حسابي»: التسجيلات المحفوظة، و**شاشة مراجعة المحتوى للمتخصص الشرعي** لاعتماد المسودات.

## التشغيل
**للمراجعة دون بناء:** الرابط المنشور أعلاه، أو شغّل المجلد `dist/` بخادم محلي (التطبيق ملف واحد يضم الواجهة والبيانات والخطوط، وتفاسير السور من `dist/dorar/`):
```bash
python3 -m http.server -d dist 8000   # ثم افتح http://localhost:8000
```

**لإعادة البناء والاختبار** (البيانات المبنية موجودة في `data/`، فلا يلزم تنزيل المصادر إلا لإعادة توليدها):
```bash
npm install                           # أدوات الاختبار (jsdom, fake-indexeddb)
python3 scripts/bundle.py             # ينتج dist/index.html
npm test                              # اختبارات المنطق والواجهة، وكلها تنتهي بـ «JS errors: none»

# إعادة توليد البيانات من المصادر (اختياري)
sh scripts/fetch_sources.sh           # تنزيل المصادر
python3 scripts/build_data.py data    # بناء البيانات وفهرس المتشابهات
python3 scripts/content_juz1.py       # محتوى التدبر والتحقق من الاقتباسات
```
**النشر:** GitHub Pages من فرع `gh-pages`، وهو محتوى `dist/` (`git subtree split --prefix dist -b gh-pages` ثم دفعه).
التسميع الصوتي المباشر يعمل في Google Chrome، والميكروفون يحتاج اتصالاً آمناً (https أو localhost).
لا يحتاج التطبيق أي مفاتيح أو حسابات؛ `ASR_ENDPOINT` اختياري وفارغ افتراضياً.

## جلب موسوعة التفسير (الدرر السنية)
النسخة الحالية تتضمن سورة الفاتحة كاملة ومقدمة سورة البقرة. لجلب بقية الموسوعة (بإذن المنظمين) على جهاز متصل بالإنترنت:
```bash
pip install requests beautifulsoup4
python3 scripts/fetch_dorar.py          # السور كلها (يستغرق وقتاً؛ مهلة 1.5 ثانية بين الطلبات)
python3 scripts/fetch_dorar.py 78 114   # أو جزء عمّ فقط للبدء
python3 scripts/bundle.py               # ينسخ الملفات إلى dist/dorar
```
يحمّل التطبيق ملف كل سورة عند فتحها فقط، فلا يكبر حجم الصفحة الرئيسية.


## المصادر والموثوقية
- نص المصحف برواية حفص عن عاصم: Tanzil (quran-simple)، موافق لطبعة مجمع الملك فهد — يُعرض دون أي تعديل.
- مقدمات السور (المقاصد، والموضوعات، والفضائل، والأسماء، والمكي والمدني)، والمعنى الإجمالي، وأسباب النزول، والفوائد التربوية والعلمية: **موسوعة التفسير — مؤسسة الدرر السنية (dorar.net)**، بإذن الجهة المنظمة. انظر PERMISSIONS.md.
- أسماء السور وتصنيفها المكي والمدني: الموسوعة القرآنية (quranpedia.net).
- التفسير الميسر: مجمع الملك فهد لطباعة المصحف الشريف.
- غريب الكلمات: السراج في بيان غريب القرآن.
- المتشابهات: حساب نصي حتمي (بدون نموذج لغوي)، ويُراجع بشرياً.
- موضوع الوجه والفوائد ومقاصد السورة مسودات تظهر بشارة «بانتظار المراجعة» حتى يعتمدها المتخصص.
- لا يولّد مثاني أي تفسير أو استنباط آلياً أثناء الاستخدام.

البيانات مأخوذة عبر مستودع quran-api المفتوح، ويجب الالتزام بشروط Tanzil ومجمع الملك فهد في النسبة وعدم التعديل.

## الخصوصية
سجل الأخطاء والتسجيلات الصوتية تُحفظ على جهاز المستخدم فقط (localStorage وIndexedDB). التسميع الصوتي يمر عبر خدمة التعرف على الكلام في المتصفح.
